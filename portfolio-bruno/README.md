# Portfólio — Bruno Eduardo

## Como abrir

1. Extraia esta pasta.
2. Abra a pasta no VS Code.
3. Abra `index.html` no navegador.

Se você tiver a extensão **Live Server** no VS Code, clique com o botão direito em `index.html` e escolha **Open with Live Server**.

## Onde editar

- `index.html` → textos, projetos, links, habilidades e informações.
- `style.css` → cores, tamanhos, espaçamentos e responsividade.
- `script.js` → menu mobile e botão de tema.
- `assets/` → coloque sua foto e seu currículo.

## Antes de publicar

Troque:
- `https://github.com/` pelo seu GitHub.
- `https://www.linkedin.com/` pelo seu LinkedIn.
- `seuemail@email.com` pelo seu e-mail.
- Os projetos pelos seus repositórios reais.
- A área `SUA FOTO` pela sua foto.
- `assets/curriculo.pdf` pelo seu currículo.

## Tecnologias

HTML5, CSS3 e JavaScript puro.
